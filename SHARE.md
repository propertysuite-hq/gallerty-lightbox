# Promo copy — Gallery & Lightbox

## GitHub repo description (one line)

A free, dependency-light Hugo partial for image galleries — grid or carousel, with an optional lightbox. No theme required.

## Short blurb (Reddit r/gohugo, Hugo Discourse, etc.)

I pulled a gallery/lightbox component out of a theme I've been building and
cleaned it up into a standalone thing — figured it might be useful to
others. It's a single partial + shortcode: pass it a list of images from a
page bundle, pick `grid` or `carousel`, and it handles the rest (Fancybox
lightbox, optional Swiper carousel). No theme dependency, no Sass/build
step required. MIT licensed, free to use.
